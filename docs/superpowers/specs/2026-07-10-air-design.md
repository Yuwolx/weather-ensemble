# 공기(Air) 디자인 시스템 — 부드럽고 감성적인 개정

2026-07-10 사용자 승인. 방향: "깔끔하지만 딱딱하다 → 부드럽고 감성적으로.
기능은 많지 않으니 부드럽게." 선택지 중 ①날씨가 분위기를 만듦(은은하게)
②형태·질감 부드럽게 ③모션의 감성 채택. 말투·기능·레이아웃은 그대로.

## 원칙 개정

- 기존 "그라데이션 금지"를 **"장식용 그라데이션 금지"**로 좁힌다.
  그날의 예보 데이터가 만드는 **공기 워시(하늘 기운)는 예외** — "데이터가 색을
  끌고 온다" 원칙의 확장이다. 멀리서 보면 여전히 흰 앱이어야 한다(채도 2~4%).
- 라벤더(#5e6ad2)는 브랜드 마크 전용으로 복귀. 선택 하이라이트에 쓰지 않는다.

## 구성요소

1. **무드 계산** — `stats.js`에 순수 함수 `dayMood(analyzedHours)` 추가.
   하루 전체의 비 오는 멤버 비율(rain.probability 평균 등)로
   `clear / unsettled / rainy` 3단계. 임계값은 config.js에. TDD.
2. **하늘 워시** — `:root`(또는 body)에 `data-mood` 속성 → CSS 변수
   (`--air`, `--air-deep`)가 무드별 톤 결정. 캔버스 상단에서 옅게 스며드는
   워시. clear=따뜻한 아이보리, unsettled=중성 미색, rainy=서늘한 블루그레이.
   활성 날짜(오늘/내일 탭)의 무드를 따라가고, 탭 전환 시 부드럽게 전이.
3. **부드러운 형태** — 스트립 막대 위 모서리 라운드, 시나리오 트랙·칩·탭·검색
   라운드 통일. 선택(picked) 하이라이트는 딱딱한 테두리 → 옅은 색 배경 채움.
   0% 시나리오의 최소폭 1.5% 가짜 점 제거(0%는 빈 트랙).
4. **감성 모션** — 막대 차오르는 이징 순화(부드러운 ease-out + 스태거),
   탭 전환 크로스페이드, 시나리오 채움 전환. `prefers-reduced-motion` 존중.
5. **모바일 미니 범례** — 스트립 아래 둥근 색점 4개(안 옴/약한 비/비/강한 비).
   기존 미해결 이슈 해소(폰에서 호버 툴팁 부재).

## 검증
